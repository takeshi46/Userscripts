# Userscripts

AdGuardで使えるユーザースクリプト集です。

## Google Play ブックス：横書き・上下スクロール

`play-books-vertical.user.js` — v1.8.8

- 本文を横書きに変更し、ルビを保持
- 操作ボタン（挿絵一覧・元の位置・表示切替）は普段は右下の小さな半透明の「☰」だけを表示（通常表示・上下スクロール共通）。押したときだけヘッダー直下に1行で開き、上下スクロールでは本文の上端を下げて重ならない
- リーダーの文字サイズ・書体・配色（ダークモード等）の設定を縦表示にも反映（読み取れない場合は白背景・18px）
- 上端・下端に近づくと前後のページを自動で読み込み（追加ボタンなし）
- ページの枠・余白をなくし、段落途中の分割を接続。幅600px以下（スマホ）では左右の余白を3pxに縮小
- 前ページ追加時に読んでいる位置を維持
- 縦表示のリンク（ブック内のCONTENTSなど）は、リーダー本来のリンクへ転送して移動（403を防止）。目次などで離れた位置へ移動した場合は縦表示を作り直す
- 「挿絵一覧」にサムネを表示し、押した挿絵へ直接移動（通常表示・上下スクロール両対応）
- リーダーが受信する章HTMLから画像位置を取得し、ページ送りなしで移動
- 画像位置を本ごとに保存し、再読み込み後も利用
- 「元の位置へ」で移動前の読書位置に復帰

登録URL：

```text
https://raw.githubusercontent.com/takeshi46/Userscripts/main/play-books-vertical.user.js
```

リーダーを再読み込みし、右上の「上下スクロール」を押すと開始します。「通常表示に戻す」で終了します。フローテキストの本文を横書きに変換します。画像として収録された文字は変換されません。

挿絵ボタンは通常表示でも使えます。起動時からリーダーの通常のデータ受信を観測し、章全体のHTMLに含まれる画像と、その直前の読書アンカーを読み取ります。章データが取得できた範囲は、未表示の挿絵にも読書URLで直接移動します。挿絵位置を特定するために全ページを順送りする必要はありません。リーダーの改ページで画像が次の見開きに送られた場合は、移動後の表示位置を最大2回だけ補正します。画像直前の本文が同じ見開きに表示される場合があります。

253ページの書籍で、起動時に全ページ分の章データを受信し、未表示だった挿絵への直接移動を確認しました。本やリーダーの仕様により章データを取得できない範囲は、従来のページ送りで探索します。元画像の縦横200px以上を対象にするため、表紙・口絵・広告画像も含みます。位置の記録はブラウザー内に保存し、本文や画像そのものは保存しません。

更新後は読書ページを再読み込みしてください。章データの取得には起動時の受信が必要です。「元の位置へ」で探索前の読書位置と表示方法に戻れます。

表示したページはメモリに保持します。長時間の読書で重くなった場合は一度通常表示に戻して再開してください。標準リーダーの読書位置は最後に読み込んだ位置へ進みます。

## PDF閲覧：広告遷移防止

`pdf.user.js` — v1.5.9

### 機能

- 外部ポップアップ・外部新規タブ広告をブロック
- 1クリックでPDFビューアへ遷移
- 必要な中間処理は維持
- PDFビューアの巻変更時広告を回避
- 正常な内部遷移は維持

### AdGuard 登録URL

```text
https://raw.githubusercontent.com/takeshi46/Userscripts/main/pdf.user.js
```

AdGuard Android では、**設定 → 拡張機能 → 拡張機能を追加する → URLから追加** で上記URLを登録します。

## 更新・インストール

AdGuard Windows版では「拡張機能 → 拡張機能を追加 → ファイルまたはURLからインポート」で追加できます。ChromeのAdGuardブラウザー拡張だけではUserscriptを実行できません。

両スクリプトに `@updateURL` と `@downloadURL` を設定しています。GitHub上のスクリプトを更新し、バージョン番号を上げることで更新配布できます。
